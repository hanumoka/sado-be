## 1. 멀티테넌시 개요

### 1.1 정의
- **멀티테넌시**: 여러 조직(병원, 클리닉)이 같은 애플리케이션을 사용하지만 데이터는 격리
- **테넌트**: 병원 또는 의료 기관 단위

### 1.2 선택한 전략
- **격리 수준**: Shared Database with Discriminator Column (tenant_id)
- **식별 방식**: JWT 토큰에 tenant_id claim 포함
- **테넌트 수**: 5개 미만 (POC 단계)

---

## 2. 데이터 격리 전략 비교

| 전략 | 장점 | 단점 | 적합성 |
|------|------|------|--------|
| **Shared DB + tenant_id** | 비용 효율적, 관리 용이, 확장성 | 격리 수준 낮음 | ⭐ POC에 최적 |
| Schema per Tenant | 중간 격리, 백업 분리 | 스키마 마이그레이션 복잡 | 중규모 |
| Database per Tenant | 최고 격리, 독립 확장 | 관리 복잡도 매우 높음 | 대규모 |

---

## 3. 아키텍처 설계

### 3.1 전체 흐름

```
[Client]
  ↓ (JWT with tenant_id claim)
[Gateway - TenantExtractionFilter]
  ↓ (X-Tenant-ID header)
[MiniPACS/BFF/Orchestrator - TenantInterceptor]
  ↓ (TenantContext.setCurrentTenantId)
[JPA Repository / MyBatis Mapper]
  ↓ (WHERE tenant_id = ?)
[MySQL Database]
```

### 3.2 컴포넌트별 책임

| 컴포넌트 | 책임 |
|---------|------|
| **Keycloak** | JWT에 tenant_id claim 발급 |
| **Gateway** | JWT에서 tenant_id 추출, 헤더로 전파 |
| **TenantInterceptor** | 헤더에서 tenant_id 파싱, TenantContext 설정 |
| **TenantContext** | ThreadLocal로 현재 tenant_id 관리 |
| **TenantFilterAspect** | JPA Filter 활성화 |
| **TenantEntityListener** | Entity 저장 시 tenant_id 자동 주입 |

### 4.2 JPA Entity 설계

**TenantAwareEntity (Base Entity)**:
```java
package com.sado.common.security.tenant;

import org.hibernate.annotations.Filter;
import org.hibernate.annotations.FilterDef;
import org.hibernate.annotations.ParamDef;

import javax.persistence.Column;
import javax.persistence.EntityListeners;
import javax.persistence.MappedSuperclass;

@FilterDef(name = "tenantFilter",
           parameters = @ParamDef(name = "tenantId", type = Long.class))
@Filter(name = "tenantFilter",
        condition = "tenant_id = :tenantId")
@MappedSuperclass
@EntityListeners(TenantEntityListener.class)
public abstract class TenantAwareEntity {

    @Column(name = "tenant_id", nullable = false)
    private Long tenantId;

    public Long getTenantId() {
        return tenantId;
    }

    public void setTenantId(Long tenantId) {
        this.tenantId = tenantId;
    }
}
```

### 4.3 TenantContext (ThreadLocal 관리)

```java
package com.sado.common.security.tenant;

public class TenantContext {

    private static final ThreadLocal<Long> currentTenant = new ThreadLocal<>();

    public static void setCurrentTenantId(Long tenantId) {
        currentTenant.set(tenantId);
    }

    public static Long getCurrentTenantId() {
        Long tenantId = currentTenant.get();
        if (tenantId == null) {
            throw new TenantNotSetException("Tenant ID not set in context");
        }
        return tenantId;
    }

    public static void clear() {
        currentTenant.remove();
    }
}
```

### 4.4 TenantInterceptor (헤더 파싱)

```java
package com.sado.common.security.tenant;

import org.springframework.stereotype.Component;
import org.springframework.web.servlet.HandlerInterceptor;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

@Component
public class TenantInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request,
                             HttpServletResponse response,
                             Object handler) {
        String tenantIdHeader = request.getHeader("X-Tenant-ID");

        if (tenantIdHeader == null) {
            throw new TenantNotProvidedException("X-Tenant-ID header missing");
        }

        Long tenantId = Long.parseLong(tenantIdHeader);
        TenantContext.setCurrentTenantId(tenantId);

        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
                                HttpServletResponse response,
                                Object handler,
                                Exception ex) {
        TenantContext.clear(); // ThreadLocal 정리
    }
}
```

### 4.5 TenantEntityListener (자동 tenant_id 주입)

```java
package com.sado.common.security.tenant;

import org.springframework.stereotype.Component;

import javax.persistence.PrePersist;

@Component
public class TenantEntityListener {

    @PrePersist
    public void setTenantId(Object entity) {
        if (entity instanceof TenantAwareEntity) {
            TenantAwareEntity tenantEntity = (TenantAwareEntity) entity;

            if (tenantEntity.getTenantId() == null) {
                Long currentTenantId = TenantContext.getCurrentTenantId();
                tenantEntity.setTenantId(currentTenantId);
            }
        }
    }
}
```

### 4.6 TenantFilterAspect (JPA Filter 활성화)

```java
package com.sado.common.security.tenant;

import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Before;
import org.hibernate.Session;
import org.springframework.stereotype.Component;

import javax.persistence.EntityManager;
import javax.persistence.PersistenceContext;

@Component
@Aspect
public class TenantFilterAspect {

    @PersistenceContext
    private EntityManager entityManager;

    @Before("execution(* com.sado..repository..*(..))")
    public void enableTenantFilter() {
        Long tenantId = TenantContext.getCurrentTenantId();
        Session session = entityManager.unwrap(Session.class);
        session.enableFilter("tenantFilter")
               .setParameter("tenantId", tenantId);
    }
}
```

### 4.7 Gateway TenantExtractionFilter (JWT 파싱)

```java
package com.sado.gateway.filter;

import org.springframework.cloud.gateway.filter.GatewayFilterChain;
import org.springframework.cloud.gateway.filter.GlobalFilter;
import org.springframework.core.Ordered;
import org.springframework.http.server.reactive.ServerHttpRequest;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationToken;
import org.springframework.stereotype.Component;
import org.springframework.web.server.ServerWebExchange;
import reactor.core.publisher.Mono;

@Component
public class TenantExtractionFilter implements GlobalFilter, Ordered {

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        return exchange.getPrincipal()
            .flatMap(principal -> {
                // Keycloak JWT에서 tenant_id claim 추출
                if (principal instanceof JwtAuthenticationToken) {
                    JwtAuthenticationToken jwt = (JwtAuthenticationToken) principal;
                    Long tenantId = jwt.getToken().getClaim("tenant_id");

                    if (tenantId == null) {
                        return Mono.error(new TenantNotProvidedException("Tenant ID not found in JWT"));
                    }

                    // 헤더에 tenant_id 추가하여 다운스트림 서비스에 전파
                    ServerHttpRequest request = exchange.getRequest().mutate()
                        .header("X-Tenant-ID", tenantId.toString())
                        .build();

                    return chain.filter(exchange.mutate().request(request).build());
                }

                return Mono.error(new UnauthorizedException("Invalid authentication"));
            });
    }

    @Override
    public int getOrder() {
        return -100; // 인증 필터 다음에 실행
    }
}
```

### 4.8 MyBatis에서 tenant_id 자동 추가

**BaseMapper XML 사용**:
```xml

        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">

    <sql id="tenantFilter">
        AND tenant_id = #{tenantId}
    </sql>
</mapper>
```

**StudyQueryMapper XML**:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">

<mapper namespace="com.sado.minipacs.mapper.StudyQueryMapper">

    <select id="findStudyListByCondition" resultType="StudyListDTO">
        SELECT
            s.study_id,
            s.study_date,
            s.status,
            p.patient_name,
            COUNT(sr.series_id) as series_count
        FROM study s
        INNER JOIN patient p ON s.patient_id = p.patient_id
        LEFT JOIN series sr ON s.study_id = sr.study_id
        WHERE 1=1
        <include refid="com.sado.common.mapper.BaseMapper.tenantFilter"/>
        <if test="patientName != null">
            AND p.patient_name LIKE CONCAT('%', #{patientName}, '%')
        </if>
        <if test="startDate != null">
            AND s.study_date >= #{startDate}
        </if>
        <if test="endDate != null">
            AND s.study_date <= #{endDate}
        </if>
        GROUP BY s.study_id, s.study_date, s.status, p.patient_name
        ORDER BY s.study_date DESC
    </select>

</mapper>
```

### 4.9 Keycloak JWT Claim 설정

**설정 방법** (Week 12):

1. **Keycloak Admin Console 접속**
2. **Realm: sado-healthcare 선택**
3. **Client Scopes → Create**
   - Name: `tenant-scope`
   - Protocol: `openid-connect`
   - Include in token scope: `ON`
4. **Mappers 탭 → Add Mapper**
   - Mapper Type: `User Attribute`
   - Name: `tenant-id-mapper`
   - User Attribute: `tenant_id`
   - Token Claim Name: `tenant_id`
   - Claim JSON Type: `long`
   - Add to ID token: `ON`
   - Add to access token: `ON`
   - Add to userinfo: `ON`
5. **Client (sado-gateway) → Client Scopes → Add `tenant-scope`**

**사용자 생성 시 tenant_id 설정**:
- Users → Add User
- Attributes 탭 → Add `tenant_id = 1` (병원 ID)

## 5. 보안 고려사항

### 5.1 Tenant 격리 검증

**테스트 시나리오**:
1. **Tenant A 사용자가 Tenant B의 Study 조회 시도** → 404 Not Found
2. **JWT의 tenant_id를 다른 값으로 조작 시도** → 401 Unauthorized (JWT 서명 검증 실패)
3. **X-Tenant-ID 헤더 없이 요청** → 400 Bad Request (TenantInterceptor에서 예외 발생)
4. **X-Tenant-ID 헤더와 JWT tenant_id 불일치** → 401 Unauthorized

### 5.2 SQL Injection 방지

- **Hibernate @Filter**: 파라미터 바인딩 사용 → SQL Injection 방지
- **MyBatis**: #{tenantId} 사용 (문자열 연결 금지)

**Bad (SQL Injection 위험)**:
```xml
<select id="findStudy">
    SELECT * FROM study WHERE tenant_id = ${tenantId}  <!-- ❌ -->
</select>
```

**Good (안전)**:
```xml
<select id="findStudy">
    SELECT * FROM study WHERE tenant_id = #{tenantId}  <!-- ✅ -->
</select>
```

### 5.3 관리자 크로스 테넌트 조회

**관리자가 모든 테넌트 데이터 조회 필요 시**:
```java
@Service
public class AdminService {

    @PersistenceContext
    private EntityManager entityManager;

    public List<Study> findAllStudiesAcrossTenants() {
        // Filter 비활성화
        Session session = entityManager.unwrap(Session.class);
        session.disableFilter("tenantFilter");

        // 모든 테넌트 데이터 조회
        return entityManager.createQuery("SELECT s FROM Study s", Study.class)
                            .getResultList();
    }
}
```

## 9. 트러블슈팅

### 문제 1: Tenant Filter가 적용 안 됨

**증상**:
```java
List<Study> studies = studyRepository.findAll();
// Tenant A 사용자인데 Tenant B 데이터도 조회됨!
```

**원인**:
- TenantFilterAspect가 실행되지 않음
- @Aspect가 Spring Bean으로 등록 안 됨

**해결**:
```java
@Configuration
@EnableAspectJAutoProxy
public class AopConfig {
    // AspectJ 활성화
}
```

### 문제 2: TenantContext가 null 반환

**증상**:
```
TenantNotSetException: Tenant ID not set in context
```

**원인**:
- TenantInterceptor가 실행되지 않음
- WebMvcConfigurer에 등록되지 않음

**해결**:
```java
@Configuration
public class WebMvcConfig implements WebMvcConfigurer {
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(tenantInterceptor)
                .addPathPatterns("/api/**");  // 경로 확인
    }
}
```

### 문제 3: MyBatis에서 tenant_id 조건 누락

**증상**:
- MyBatis 쿼리에서 다른 테넌트 데이터 조회됨

**원인**:
- XML Mapper에 tenant_id 조건 없음

**해결**:
```xml
<!-- 모든 쿼리에 tenantFilter 추가 -->
<select id="findStudyList">
    SELECT * FROM study
    WHERE 1=1
    <include refid="com.sado.common.mapper.BaseMapper.tenantFilter"/>
</select>
```
