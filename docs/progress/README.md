# 📁 주차별 진행 상황 폴더

> 각 주차의 상세한 학습 내용, 작업 내역, 트러블슈팅을 기록합니다.

---

## 📋 폴더 구조

```
progress/
├── README.md           # 이 파일 (사용 가이드)
├── week-01.md         # Week 1 상세 진행 상황
├── week-02.md         # Week 2 상세 진행 상황
├── ...
└── week-16.md         # Week 16 상세 진행 상황
```

---

## 📝 주차별 문서 작성 가이드

### 파일명 규칙
- `week-XX.md` (XX는 01-16 형식)
- 예: `week-01.md`, `week-12.md`

### 문서 템플릿

각 주차 문서는 아래 템플릿을 따릅니다:

```markdown
# Week XX: [주차 주제]

> **기간**: YYYY-MM-DD ~ YYYY-MM-DD
> **상태**: 🔄 진행중 | ✅ 완료 | ⏸️ 대기중
> **진행률**: X%

---

## 🎯 주간 목표

- 목표 1
- 목표 2
- 목표 3

---

## 📚 학습 내용

### 1. [주제 1]
**학습 시간**: X시간
**참고 자료**:
- 링크 1
- 링크 2

**핵심 정리**:
- 핵심 개념 1
- 핵심 개념 2

- [ ] 학습 노트: `learning/weekXX-topic.md`
- [ ] 블로그 초안 (선택)

---
```

## 🔄 업데이트 주기

- **매일**: 트러블슈팅, 작업 체크리스트 업데이트
- **주 중간**: 학습 내용 정리
- **주말**: 주간 회고, 다음 주 계획 작성

---

## 🎯 작성 목적

1. **학습 내용 체계화**: 배운 내용을 정리하여 장기 기억으로 전환
2. **문제 해결 이력 관리**: 같은 문제 재발 시 빠른 해결
3. **진행 상황 추적**: 프로젝트 진행도 가시화
4. **포트폴리오 자료**: 면접 시 구체적인 경험 설명 가능
