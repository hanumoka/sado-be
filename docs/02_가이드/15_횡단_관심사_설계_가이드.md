## 2. Resilience Patterns (회복탄력성)

### 2.1 필요성

마이크로서비스 환경에서 **서비스 간 통신 실패**는 피할 수 없습니다. 회복탄력성 패턴은 장애 전파를 방지합니다.

```
[BFF] ──요청──> [MiniPACS] ──X 실패──>
       │
       ├── Circuit Breaker: 빠른 실패 반환
       ├── Retry: 일시적 오류 재시도
       ├── Timeout: 응답 대기 시간 제한
       └── Fallback: 대체 응답 제공
```

### 2.2 Resilience4j 핵심 패턴

| 패턴 | 용도 | 적용 시기 |
|-----|------|----------|
| **Circuit Breaker** | 연속 실패 시 빠른 실패 반환, 백엔드 보호 | Week 13 |
| **Retry** | 일시적 오류(네트워크 지연 등) 재시도 | Week 4 |
| **Timeout** | 응답 대기 시간 제한, 리소스 해제 | Week 4 |
| **Bulkhead** | 스레드 풀 분리, 리소스 격리 | Week 13 |
| **Rate Limiter** | 요청 속도 제한 | Week 13 |
| **Fallback** | 실패 시 대체 응답 제공 | Week 13 |

### 2.5 Feign Client 적용

```java
// BFF → MiniPACS 호출
@FeignClient(name = "minipacs", url = "${service.minipacs.url}")
public interface MiniPacsClient {

    @Retry(name = "minipacs")
    @CircuitBreaker(name = "minipacs", fallbackMethod = "getStudyFallback")
    @TimeLimiter(name = "minipacs")
    @GetMapping("/api/v1/studies/{studyId}")
    StudyDto getStudy(@PathVariable String studyId);

    @Retry(name = "minipacs")
    @CircuitBreaker(name = "minipacs", fallbackMethod = "getStudiesFallback")
    @GetMapping("/api/v1/studies")
    List<StudyDto> getStudies(@RequestParam Long tenantId);

    // Fallback 메서드
    default StudyDto getStudyFallback(String studyId, Exception e) {
        log.warn("MiniPACS getStudy failed for studyId={}, returning fallback", studyId, e);
        return StudyDto.builder()
            .studyId(studyId)
            .status("UNAVAILABLE")
            .message("서비스 일시 불가")
            .build();
    }

    default List<StudyDto> getStudiesFallback(Long tenantId, Exception e) {
        log.warn("MiniPACS getStudies failed for tenantId={}, returning empty list", tenantId, e);
        return Collections.emptyList();
    }
}
```

### 3.2 Correlation ID (요청 추적)

모든 요청에 고유 ID를 부여하여 분산 시스템에서 요청 흐름을 추적합니다.

```java
// common-core 모듈
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class CorrelationIdFilter extends OncePerRequestFilter {

    public static final String CORRELATION_ID_HEADER = "X-Request-ID";
    public static final String CORRELATION_ID_MDC_KEY = "correlationId";
    public static final String TENANT_ID_MDC_KEY = "tenantId";

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain)
            throws ServletException, IOException {

        String correlationId = request.getHeader(CORRELATION_ID_HEADER);
        if (correlationId == null || correlationId.isBlank()) {
            correlationId = UUID.randomUUID().toString();
        }

        // MDC에 컨텍스트 설정 (로깅에 자동 포함)
        MDC.put(CORRELATION_ID_MDC_KEY, correlationId);

        // TenantContext가 설정되어 있으면 MDC에도 추가
        Long tenantId = TenantContext.getCurrentTenantId();
        if (tenantId != null) {
            MDC.put(TENANT_ID_MDC_KEY, tenantId.toString());
        }

        try {
            // 응답 헤더에도 Correlation ID 포함
            response.setHeader(CORRELATION_ID_HEADER, correlationId);
            filterChain.doFilter(request, response);
        } finally {
            MDC.clear();
        }
    }
}
```

**Feign Client에서 Correlation ID 전파:**

```java
// common-core 모듈
@Component
public class CorrelationIdFeignInterceptor implements RequestInterceptor {

    @Override
    public void apply(RequestTemplate template) {
        String correlationId = MDC.get(CorrelationIdFilter.CORRELATION_ID_MDC_KEY);
        if (correlationId != null) {
            template.header(CorrelationIdFilter.CORRELATION_ID_HEADER, correlationId);
        }
    }
}
```

#### 🔒 Filter 실행 순서 (중요) ⭐ NEW

**횡단 관심사 Filter Chain 통합 순서**:
```
1. SecurityContextPersistenceFilter (Spring Security 기본)
2. JwtAuthenticationFilter (Spring Security OAuth2)
   → JWT 검증 및 Authentication 객체 생성
3. JwtTenantFilter (Order = 1) ⭐
   → JWT에서 tenant_id 추출 → TenantContext 설정
   → 참고: guides/12_멀티테넌시_설계_가이드.md
4. CorrelationIdFilter (Order = 2) ⭐ 이 섹션
   → X-Request-ID 생성 및 MDC 설정
5. LoggingFilter (Order = 3)
   → 구조화 로깅 (tenant_id, correlationId 포함)
6. RateLimitFilter (Order = 4) - Optional
   → API 요청 제한 (Redis 기반)
7. Controller 실행
8. GlobalExceptionHandler
   → RFC 7807 Problem Details 응답
```

**FilterRegistrationBean 설정 예시**:
```java
@Configuration
public class FilterConfig {

    @Bean
    public FilterRegistrationBean<CorrelationIdFilter> correlationIdFilter() {
        FilterRegistrationBean<CorrelationIdFilter> registration = new FilterRegistrationBean<>();
        registration.setFilter(new CorrelationIdFilter());
        registration.addUrlPatterns("/api/*");
        registration.setOrder(2); // JwtTenantFilter(1) 이후
        return registration;
    }

    @Bean
    public FilterRegistrationBean<LoggingFilter> loggingFilter() {
        FilterRegistrationBean<LoggingFilter> registration = new FilterRegistrationBean<>();
        registration.setFilter(new LoggingFilter());
        registration.addUrlPatterns("/api/*");
        registration.setOrder(3); // CorrelationIdFilter(2) 이후
        return registration;
    }
}
```

**⚠️ 주의사항**:
- Filter 순서가 잘못되면 MDC에 tenant_id/correlationId가 없어 로깅 누락 발생
- `setOrder()` 값이 작을수록 먼저 실행
- 보안 Filter(JwtTenantFilter)는 항상 Observability Filter(CorrelationId) 보다 먼저 실행

### 3.3 구조화 로깅 (Structured Logging)

**logback-spring.xml:**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <include resource="org/springframework/boot/logging/logback/defaults.xml"/>

    <!-- 개발 환경: 콘솔 출력 (읽기 쉬운 형식) -->
    <springProfile name="local,dev">
        <appender name="CONSOLE" class="ch.qos.logback.core.ConsoleAppender">
            <encoder>
                <pattern>%d{HH:mm:ss.SSS} [%thread] %-5level %logger{36} [%X{correlationId}] [tenant:%X{tenantId}] - %msg%n</pattern>
            </encoder>
        </appender>
        <root level="INFO">
            <appender-ref ref="CONSOLE"/>
        </root>
    </springProfile>

    <!-- 운영 환경: JSON 구조화 로깅 (ELK 연동) -->
    <springProfile name="prod,staging">
        <appender name="JSON" class="ch.qos.logback.core.ConsoleAppender">
            <encoder class="net.logstash.logback.encoder.LoggingEventCompositeJsonEncoder">
                <providers>
                    <timestamp>
                        <fieldName>timestamp</fieldName>
                        <pattern>yyyy-MM-dd'T'HH:mm:ss.SSSZ</pattern>
                    </timestamp>
                    <logLevel>
                        <fieldName>level</fieldName>
                    </logLevel>
                    <message>
                        <fieldName>message</fieldName>
                    </message>
                    <loggerName>
                        <fieldName>logger</fieldName>
                        <shortenedLoggerNameLength>36</shortenedLoggerNameLength>
                    </loggerName>
                    <threadName>
                        <fieldName>thread</fieldName>
                    </threadName>
                    <mdc>
                        <includeMdcKeyName>correlationId</includeMdcKeyName>
                        <includeMdcKeyName>tenantId</includeMdcKeyName>
                        <includeMdcKeyName>traceId</includeMdcKeyName>
                        <includeMdcKeyName>spanId</includeMdcKeyName>
                    </mdc>
                    <stackTrace>
                        <fieldName>stackTrace</fieldName>
                        <throwableConverter class="net.logstash.logback.stacktrace.ShortenedThrowableConverter">
                            <maxDepthPerThrowable>30</maxDepthPerThrowable>
                            <maxLength>2048</maxLength>
                            <rootCauseFirst>true</rootCauseFirst>
                        </throwableConverter>
                    </stackTrace>
                    <pattern>
                        <pattern>
                            {
                                "service": "${springAppName:-sado}",
                                "environment": "${SPRING_PROFILES_ACTIVE:-local}"
                            }
                        </pattern>
                    </pattern>
                </providers>
            </encoder>
        </appender>
        <root level="INFO">
            <appender-ref ref="JSON"/>
        </root>
    </springProfile>
</configuration>
```

### 4.2 GlobalExceptionHandler

```java
// common-core 모듈
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    // 비즈니스 예외 (4xx)
    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<ProblemDetail> handleBusinessException(
            BusinessException ex, HttpServletRequest request) {

        log.warn("Business exception: {}", ex.getMessage());

        ProblemDetail problem = ProblemDetail.forStatus(ex.getStatus());
        problem.setType(URI.create("https://api.sado.com/errors/" + ex.getErrorCode()));
        problem.setTitle(ex.getTitle());
        problem.setDetail(ex.getMessage());
        problem.setInstance(URI.create(request.getRequestURI()));
        enrichWithContext(problem);

        return ResponseEntity.status(ex.getStatus()).body(problem);
    }

    // 리소스 없음 (404)
    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ProblemDetail> handleResourceNotFound(
            ResourceNotFoundException ex, HttpServletRequest request) {

        log.warn("Resource not found: {}", ex.getMessage());

        ProblemDetail problem = ProblemDetail.forStatus(HttpStatus.NOT_FOUND);
        problem.setType(URI.create("https://api.sado.com/errors/resource-not-found"));
        problem.setTitle("Resource Not Found");
        problem.setDetail(ex.getMessage());
        problem.setInstance(URI.create(request.getRequestURI()));
        enrichWithContext(problem);

        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(problem);
    }

    // 유효성 검증 실패 (400)
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ProblemDetail> handleValidation(
            MethodArgumentNotValidException ex, HttpServletRequest request) {

        log.warn("Validation failed: {}", ex.getMessage());

        ProblemDetail problem = ProblemDetail.forStatus(HttpStatus.BAD_REQUEST);
        problem.setType(URI.create("https://api.sado.com/errors/validation-failed"));
        problem.setTitle("Validation Failed");

        Map<String, String> errors = ex.getBindingResult().getFieldErrors().stream()
            .collect(Collectors.toMap(
                FieldError::getField,
                FieldError::getDefaultMessage,
                (a, b) -> a + "; " + b
            ));

        problem.setProperty("errors", errors);
        problem.setInstance(URI.create(request.getRequestURI()));
        enrichWithContext(problem);

        return ResponseEntity.badRequest().body(problem);
    }

    // 테넌트 미제공 (401)
    @ExceptionHandler(TenantNotProvidedException.class)
    public ResponseEntity<ProblemDetail> handleTenantNotProvided(
            TenantNotProvidedException ex, HttpServletRequest request) {

        log.error("Tenant not provided: {}", ex.getMessage());

        ProblemDetail problem = ProblemDetail.forStatus(HttpStatus.UNAUTHORIZED);
        problem.setType(URI.create("https://api.sado.com/errors/tenant-not-provided"));
        problem.setTitle("Tenant Not Provided");
        problem.setDetail(ex.getMessage());
        problem.setInstance(URI.create(request.getRequestURI()));
        enrichWithContext(problem);

        return ResponseEntity.status(HttpStatus.UNAUTHORIZED).body(problem);
    }

    // 서버 오류 (500) - 예상치 못한 오류
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ProblemDetail> handleUnexpected(
            Exception ex, HttpServletRequest request) {

        log.error("Unexpected error occurred", ex);

        ProblemDetail problem = ProblemDetail.forStatus(HttpStatus.INTERNAL_SERVER_ERROR);
        problem.setType(URI.create("https://api.sado.com/errors/internal-error"));
        problem.setTitle("Internal Server Error");
        problem.setDetail("An unexpected error occurred. Please contact support.");
        problem.setInstance(URI.create(request.getRequestURI()));
        enrichWithContext(problem);

        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).body(problem);
    }

    // 공통 컨텍스트 추가
    private void enrichWithContext(ProblemDetail problem) {
        problem.setProperty("timestamp", Instant.now().toString());

        String correlationId = MDC.get("correlationId");
        if (correlationId != null) {
            problem.setProperty("correlationId", correlationId);
        }

        Long tenantId = TenantContext.getCurrentTenantId();
        if (tenantId != null) {
            problem.setProperty("tenantId", tenantId);
        }
    }
}
```

### 5.3 Custom Health Indicator

```java
// Kafka Health Indicator
@Component
public class KafkaHealthIndicator implements HealthIndicator {

    private final KafkaAdmin kafkaAdmin;

    @Override
    public Health health() {
        try {
            Collection<Node> nodes = kafkaAdmin.describeCluster()
                .nodes()
                .get(5, TimeUnit.SECONDS);

            if (nodes.isEmpty()) {
                return Health.down()
                    .withDetail("kafka", "No brokers available")
                    .build();
            }

            return Health.up()
                .withDetail("kafka", "Connected")
                .withDetail("brokers", nodes.size())
                .build();
        } catch (Exception e) {
            return Health.down()
                .withDetail("kafka", "Connection failed")
                .withException(e)
                .build();
        }
    }
}

// SeaweedFS Health Indicator
@Component
@ConditionalOnProperty(prefix = "seaweedfs", name = "enabled", havingValue = "true")
public class SeaweedFSHealthIndicator implements HealthIndicator {

    private final SeaweedFSClient seaweedFSClient;

    @Override
    public Health health() {
        try {
            boolean isAvailable = seaweedFSClient.ping();
            if (isAvailable) {
                return Health.up()
                    .withDetail("seaweedfs", "Available")
                    .build();
            } else {
                return Health.down()
                    .withDetail("seaweedfs", "Not available")
                    .build();
            }
        } catch (Exception e) {
            return Health.down()
                .withDetail("seaweedfs", "Connection failed")
                .withException(e)
                .build();
        }
    }
}
```

## 6. API Versioning (API 버전 관리)

### 6.1 버전 전략: URI 버전

```
/api/v1/studies      # 현재 버전
/api/v2/studies      # 새 버전 (breaking change 발생 시)
```

**선택 이유:**
- 명확하고 직관적
- 캐싱 용이
- 디버깅 편리
- 대부분의 기업에서 채택

### 6.2 Controller 설정

```java
// 버전 1
@RestController
@RequestMapping("/api/v1/studies")
@RequiredArgsConstructor
public class StudyControllerV1 {

    private final StudyService studyService;

    @GetMapping("/{studyId}")
    public ResponseEntity<StudyDto> getStudy(@PathVariable String studyId) {
        return ResponseEntity.ok(studyService.getStudy(studyId));
    }
}

// 버전 2 (필요 시 추가)
@RestController
@RequestMapping("/api/v2/studies")
@RequiredArgsConstructor
public class StudyControllerV2 {

    private final StudyService studyService;

    @GetMapping("/{studyId}")
    public ResponseEntity<StudyDtoV2> getStudy(@PathVariable String studyId) {

    }
}
```

### 6.4 버전 전환 정책

1. **새 버전 추가**: 기존 버전 유지, 새 버전 병행
2. **Deprecation 공지**: 6개월 전 공지
3. **이전 버전 제거**: 공지 후 6개월 뒤 제거
