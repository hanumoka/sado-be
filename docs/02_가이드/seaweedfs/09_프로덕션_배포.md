## Master 클러스터 구성

### 3대 Master (Raft HA)

**docker-compose.yml** (프로덕션):

```yaml
services:
  master1:
    image: chrislusf/seaweedfs:latest
    command: >
      master
      -ip=master1
      -port=9333
      -peers=master1:9333,master2:9333,master3:9333
      -mdir=/data
      -defaultReplication=001
      -volumeSizeLimitMB=30000
      -metrics.address=prometheus-pushgateway:9091
    volumes:
      - master1-data:/data
    networks:
      - seaweedfs-net
    restart: unless-stopped

  master2:
    image: chrislusf/seaweedfs:latest
    command: >
      master
      -ip=master2
      -port=9333
      -peers=master1:9333,master2:9333,master3:9333
      -mdir=/data
      -defaultReplication=001
      -volumeSizeLimitMB=30000
      -metrics.address=prometheus-pushgateway:9091
    volumes:
      - master2-data:/data
    networks:
      - seaweedfs-net
    restart: unless-stopped

  master3:
    image: chrislusf/seaweedfs:latest
    command: >
      master
      -ip=master3
      -port=9333
      -peers=master1:9333,master2:9333,master3:9333
      -mdir=/data
      -defaultReplication=001
      -volumeSizeLimitMB=30000
      -metrics.address=prometheus-pushgateway:9091
    volumes:
      - master3-data:/data
    networks:
      - seaweedfs-net
    restart: unless-stopped
```

### Master 설정 권장사항

| 옵션 | 권장값 | 이유 |
|-----|-------|------|
| `-volumeSizeLimitMB` | 30000 (30GB) | 큰 Volume = 적은 메타데이터 |
| `-defaultReplication` | 001 | 최소 복제 (서버 장애 대비) |
| `-volumePreallocate` | false | 디스크 공간 절약 |
| `-metrics.address` | pushgateway:9091 | 중앙 메트릭 수집 |

## Volume Server 구성

### 다중 Volume Server

```yaml
services:
  volume1:
    image: chrislusf/seaweedfs:latest
    command: >
      volume
      -mserver=master1:9333,master2:9333,master3:9333
      -port=8080
      -ip=volume1
      -max=100
      -dataCenter=dc1
      -rack=rack1
      -compactionMBps=50
      -index=leveldb
      -metrics.address=prometheus-pushgateway:9091
    volumes:
      - volume1-data:/data
    networks:
      - seaweedfs-net
    restart: unless-stopped
    deploy:
      resources:
        limits:
          memory: 4G
        reservations:
          memory: 2G

  volume2:
    image: chrislusf/seaweedfs:latest
    command: >
      volume
      -mserver=master1:9333,master2:9333,master3:9333
      -port=8080
      -ip=volume2
      -max=100
      -dataCenter=dc1
      -rack=rack1
      -compactionMBps=50
      -index=leveldb
      -metrics.address=prometheus-pushgateway:9091
    volumes:
      - volume2-data:/data
    networks:
      - seaweedfs-net
    restart: unless-stopped
```

### Volume Server 설정 권장사항

| 옵션 | 권장값 | 이유 |
|-----|-------|------|
| `-max` | 100 | Volume 개수 여유 확보 |
| `-compactionMBps` | 50 | I/O 부담 제한 |
| `-index` | leveldb | 메모리 사용량 감소 |
| `-dataCenter` | dc1 | 토폴로지 인식 복제 |
| `-rack` | rack1 | 랙 인식 복제 |

## 네트워크 구성

### 포트 목록

| 컴포넌트 | 포트 | 프로토콜 | 방화벽 |
|---------|------|---------|-------|
| Master HTTP | 9333 | TCP | 내부 + 외부 |
| Master gRPC | 19333 | TCP | 내부 |
| Volume HTTP | 8080 | TCP | 내부 + 외부 |
| Filer HTTP | 8888 | TCP | 내부 + 외부 |
| Filer gRPC | 18888 | TCP | 내부 |
| Metrics | 9327 | TCP | 내부 (Prometheus) |

### Multi-homed 서버 설정

```bash
# 서버에 여러 IP가 있을 때
weed master -ip=192.168.1.10 -ip.bind=0.0.0.0
weed volume -ip=192.168.1.11 -publicUrl=public.example.com:8080
```

## 디스크 관리

### 디스크 용량 모니터링

**알람 임계값**:
- **Warning**: 80% 사용
- **Critical**: 90% 사용

**Prometheus Alert**:
```yaml
- alert: SeaweedFSDiskHigh
  expr: volume_server_disk_size_bytes_used / volume_server_disk_size_bytes_total > 0.8
  for: 10m
  labels:
    severity: warning
```

### Volume 추가

```bash
# Master에 새 Volume 요청
curl "http://localhost:9333/vol/grow?count=10&replication=001"
```

### Compaction 스케줄링

```bash
# Cron으로 주간 Compaction
0 2 * * 0 curl "http://localhost:9333/vol/vacuum?garbageThreshold=0.3"
```

## 백업 전략

### Volume 백업

**방법 1: Volume 파일 복사**
```bash
# Volume Server 정지
docker stop seaweedfs-volume

# 파일 복사
tar -czf volume-backup-$(date +%Y%m%d).tar.gz /data/volumes/

# Volume Server 재시작
docker start seaweedfs-volume
```

**방법 2: Snapshot (LVM/ZFS)**
```bash
# LVM Snapshot
lvcreate -L 10G -s -n volume-snapshot /dev/vg0/volumes
```

### Filer 메타데이터 백업

```bash
# MySQL 백업
mysqldump -u root -p seaweedfs_filer > filer-backup-$(date +%Y%m%d).sql

# 자동화 (Cron)
0 3 * * * /usr/local/bin/backup-seaweedfs.sh
```

## 보안 설정

### JWT 인증 (Filer)

```toml
# filer.toml
[jwt.signing]
key = "your-secret-key-here"
expires_after_seconds = 3600
```

**요청 시 JWT 토큰 포함**:
```bash
curl -H "Authorization: Bearer <JWT_TOKEN>" \
  http://localhost:8888/path/to/file
```

### SSL/TLS 암호화

```bash
# Master with TLS
weed master \
  -cert.file=/path/to/cert.pem \
  -key.file=/path/to/key.pem

# Volume with TLS
weed volume \
  -cert.file=/path/to/cert.pem \
  -key.file=/path/to/key.pem \
  -mserver=master:9333
```

### 방화벽

```bash
# iptables 규칙 예시
iptables -A INPUT -p tcp --dport 9333 -s 192.168.1.0/24 -j ACCEPT
iptables -A INPUT -p tcp --dport 9333 -j DROP
```

## Kubernetes 배포

### Helm Chart

```bash
# seaweedfs-operator 설치
helm repo add seaweedfs https://seaweedfs.github.io/seaweedfs-operator
helm install seaweedfs seaweedfs/seaweedfs
```

### StatefulSet 예시

```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: seaweedfs-master
spec:
  serviceName: seaweedfs-master
  replicas: 3
  selector:
    matchLabels:
      app: seaweedfs-master
  template:
    metadata:
      labels:
        app: seaweedfs-master
    spec:
      containers:
      - name: master
        image: chrislusf/seaweedfs:latest
        command: ["weed", "master"]
        args:
          - "-mdir=/data"
          - "-peers=seaweedfs-master-0.seaweedfs-master:9333,seaweedfs-master-1.seaweedfs-master:9333,seaweedfs-master-2.seaweedfs-master:9333"
        ports:
        - containerPort: 9333
        volumeMounts:
        - name: data
          mountPath: /data
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          storage: 10Gi
```

## 트러블슈팅

### 문제 1: Volume 꽉 참

**증상**:
```json
{"error": "no free volumes"}
```

**해결**:
```bash
# 1. 새 Volume 추가
curl "http://localhost:9333/vol/grow?count=10"

# 2. Compaction 실행
curl "http://localhost:9333/vol/vacuum?garbageThreshold=0.3"
```

### 문제 2: Master 리더 없음

**증상**:
```bash
curl http://localhost:9333/cluster/status
# {"IsLeader": false, "Leader": ""}
```

**해결**:
```bash
# Master 로그 확인
docker logs seaweedfs-master1

# 과반수(2/3) 이상 살아있는지 확인
docker ps | grep seaweedfs-master
```
