# 07. 모니터링 및 운영

> **학습 목표**: Prometheus와 Grafana로 SeaweedFS를 모니터링하고 운영합니다.

---

## Prometheus 메트릭 수집

### 메트릭 노출 방법

SeaweedFS는 **2가지 방식**으로 메트릭을 제공합니다:

#### 1. Pull 방식 (Metrics Port)

```bash
# Master
weed master -metricsPort=9327

# Volume
weed volume -metricsPort=9327

# Filer
weed filer -metricsPort=9327
```

**Prometheus scrape 설정** (`prometheus.yml`):
```yaml
scrape_configs:
  - job_name: 'seaweedfs-master'
    static_configs:
      - targets: ['localhost:9327']

  - job_name: 'seaweedfs-volume'
    static_configs:
      - targets: ['localhost:9327']
```

#### 2. Push 방식 (Push Gateway)

```bash
weed master -metrics.address=localhost:9091
weed volume -metrics.address=localhost:9091
weed filer -metrics.address=localhost:9091
```

## 주요 모니터링 지표

### Master 메트릭

| 메트릭 | 설명 | 중요도 |
|-------|------|-------|
| `master_volume_count` | 총 Volume 개수 | ⭐⭐⭐ |
| `master_volume_layout_*` | Volume 레이아웃 분포 | ⭐⭐ |
| `master_leader` | 리더 여부 (1 or 0) | ⭐⭐⭐ |
| `raft_*` | Raft 합의 메트릭 | ⭐⭐⭐ |

### Volume 메트릭

| 메트릭 | 설명 | 중요도 |
|-------|------|-------|
| `volume_server_disk_size_*` | 디스크 사용량 | ⭐⭐⭐ |
| `volume_server_request_*` | 요청 수 (read/write) | ⭐⭐⭐ |
| `volume_server_bytes_*` | 전송 바이트 수 | ⭐⭐ |
| `volume_server_volume_*` | Volume 상태 | ⭐⭐ |

### Filer 메트릭

| 메트릭 | 설명 | 중요도 |
|-------|------|-------|
| `filer_request_*` | Filer 요청 수 | ⭐⭐⭐ |
| `filer_store_*` | 메타데이터 저장소 메트릭 | ⭐⭐ |

### 공식 대시보드

**import 방법**:
1. Grafana → Dashboards → Import
2. Dashboard ID: `10423` 입력
3. Prometheus Data Source 선택

**다운로드**:
```bash
wget https://raw.githubusercontent.com/seaweedfs/seaweedfs/master/other/metrics/grafana_seaweedfs.json
```

### 주요 패널

- **Cluster Overview**: 전체 클러스터 상태
- **Volume Server Disk Usage**: 디스크 사용률
- **Request Rate**: 초당 요청 수
- **Throughput**: 처리량 (MB/s)
- **Latency**: 응답 시간

## Health Check

### 엔드포인트

```bash
# Master Health Check
curl http://localhost:10400/cluster/healthz

# Volume Health Check
curl http://localhost:10402/healthz

# Filer Health Check
curl http://localhost:10403/healthz
```

### Docker Compose Healthcheck

```yaml
services:
  seaweedfs-master:
    healthcheck:
      test: ["CMD", "wget", "-q", "-O-", "http://localhost:9333/cluster/healthz"]
      interval: 10s
      timeout: 5s
      retries: 3
      start_period: 30s

  seaweedfs-volume:
    healthcheck:
      test: ["CMD", "wget", "-q", "-O-", "http://localhost:8080/healthz"]
      interval: 10s
      timeout: 5s
      retries: 3
```

## 알람 설정

### Prometheus Alerting Rules

**seaweedfs-alerts.yml**:
```yaml
groups:
  - name: seaweedfs
    interval: 30s
    rules:
      # Master 리더 없음
      - alert: SeaweedFSNoLeader
        expr: sum(master_leader) == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "SeaweedFS has no leader"
          description: "Master cluster has no elected leader"

      # 디스크 공간 부족
      - alert: SeaweedFSDiskFull
        expr: volume_server_disk_size_bytes_used / volume_server_disk_size_bytes_total > 0.9
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "SeaweedFS disk usage high ({{ $value }}%)"

      # Volume Server 다운
      - alert: SeaweedFSVolumeDown
        expr: up{job="seaweedfs-volume"} == 0
        for: 2m
        labels:
          severity: critical
        annotations:
          summary: "SeaweedFS Volume Server is down"
```

## 로그 관리

### 로그 레벨

```bash
# 기본 로그
weed master -v=0

# 상세 로그
weed master -v=1

# 디버그 로그
weed master -v=2
```

### 로그 파일

```bash
# 로그 파일 리다이렉션
weed master > /var/log/seaweedfs/master.log 2>&1

# logrotate 설정
/etc/logrotate.d/seaweedfs:
/var/log/seaweedfs/*.log {
    daily
    rotate 7
    compress
    missingok
    notifempty
}
```

## Compaction (공간 회수)

### 자동 Compaction

```bash
# Volume Server 시작 시 자동 Compaction 설정
weed volume -compactionMBps=50
```

### 수동 Compaction

```bash
# 특정 Volume Compaction
curl "http://localhost:10402/admin/volume/compact?volumeId=3"

# 모든 Volume Compaction
curl "http://localhost:10400/vol/vacuum?garbageThreshold=0.3"
```

## SADO 프로젝트 모니터링

### Prometheus Docker Compose

```yaml
services:
  prometheus:
    image: prom/prometheus:latest
    container_name: sado-prometheus
    ports:
      - "10500:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - prometheus-data:/prometheus
    networks:
      - sado-network

  grafana:
    image: grafana/grafana:latest
    container_name: sado-grafana
    ports:
      - "10501:3000"
    volumes:
      - grafana-data:/var/lib/grafana
    networks:
      - sado-network
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
```

**prometheus.yml**:
```yaml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'seaweedfs-master'
    static_configs:
      - targets: ['seaweedfs-master:9327']

  - job_name: 'seaweedfs-volume'
    static_configs:
      - targets: ['seaweedfs-volume:9327']
```
