## 설치 방법 개요

### 설치 옵션

SeaweedFS는 다양한 방법으로 설치 가능합니다:

| 방법 | 사용 시나리오 | 난이도 |
|-----|-------------|-------|
| **Docker Compose** | 로컬 개발, 빠른 테스트 | ⭐ 쉬움 (추천) |
| **Bare Metal** | 프로덕션 환경 | ⭐⭐ 중간 |
| **Kubernetes** | 클라우드 네이티브 환경 | ⭐⭐⭐ 어려움 |
| **All-in-One** | 간단한 테스트 | ⭐ 매우 쉬움 |

**SADO 프로젝트 선택**: **Docker Compose** (기존 인프라와 일관성)

### Docker Image

**공식 이미지**:
```bash
docker pull chrislusf/seaweedfs:latest
```

**최신 버전** (2025-12-30 기준):
- 버전: `3.80`
- 이미지 크기: ~50MB
- 베이스: Alpine Linux

## Docker Compose 기본 설치

### 최소 구성 (단일 노드)

**docker-compose.yml** (개발 환경):

```yaml
version: '3.8'

services:
  master:
    image: chrislusf/seaweedfs:latest
    container_name: seaweedfs-master
    command: 'master -ip=master -port=9333'
    ports:
      - "9333:9333"      # HTTP API
      - "19333:19333"    # gRPC
    volumes:
      - seaweedfs-master-data:/data
    networks:
      - seaweedfs-net

  volume:
    image: chrislusf/seaweedfs:latest
    container_name: seaweedfs-volume
    command: 'volume -mserver=master:9333 -port=8080 -ip=volume -max=10'
    ports:
      - "8080:8080"
    volumes:
      - seaweedfs-volume-data:/data
    networks:
      - seaweedfs-net
    depends_on:
      - master

  filer:
    image: chrislusf/seaweedfs:latest
    container_name: seaweedfs-filer
    command: 'filer -master=master:9333 -ip=filer'
    ports:
      - "8888:8888"      # HTTP API
      - "18888:18888"    # gRPC
    volumes:
      - seaweedfs-filer-data:/data
    networks:
      - seaweedfs-net
    depends_on:
      - master

volumes:
  seaweedfs-master-data:
  seaweedfs-volume-data:
  seaweedfs-filer-data:

networks:
  seaweedfs-net:
    driver: bridge
```

### 실행

```bash
# 컨테이너 시작
docker-compose up -d

# 로그 확인
docker-compose logs -f

# 상태 확인
docker-compose ps
```

### 확인

```bash
# Master 상태 확인
curl http://localhost:9333/cluster/status

# Volume 상태 확인
curl http://localhost:8080/status

# Filer 상태 확인
curl http://localhost:8888/
```

## SADO 프로젝트 통합

### 포트 매핑 전략

SADO 프로젝트는 **10000번대 포트 표준화**를 사용합니다:

| 서비스 범위 | 포트 범위 | 할당 |
|-----------|----------|------|
| 인프라 (DB, Kafka) | 10100-10199 | MySQL: 10100 |
| 백엔드 API | 10200-10299 | Gateway: 10200, MiniPACS: 10201 |
| 프론트엔드 | 10300-10399 | Vite: 10300 |
| **객체 스토리지** | **10400-10499** | **SeaweedFS 할당** ⭐ |

**SeaweedFS 포트 할당**:
- **Master**: 10400 (HTTP), 10401 (gRPC)
- **Volume**: 10402 (HTTP)
- **Filer**: 10403 (HTTP), 10404 (gRPC), 10405 (S3 API) - 필수

**Filer 필수 이유**:
1. DICOMweb 표준 준수 (WADO-RS, QIDO-RS의 path-based URL)
2. OHIF Viewer S3 API 호환성
3. AI 서비스 (sado_ai) 표준 S3 SDK 사용
4. Web UI 디버깅 인터페이스 (http://localhost:10403)
5. 계층적 파일 관리 (썸네일, 트랜스코딩)

## 설정 파일 상세

### Master 설정

**주요 옵션**:

```bash
weed master \
  -ip=master \                  # 서버 IP/호스트명
  -port=9333 \                  # HTTP 포트
  -mdir=/data/master \          # 데이터 디렉토리
  -defaultReplication=000 \     # 복제 정책 (000=복제 없음)
  -volumeSizeLimitMB=30000 \    # Volume 최대 크기 (30GB)
  -volumePreallocate=false \    # Volume 사전 할당 여부
  -metrics.address=localhost:9091  # Prometheus Push Gateway
```

**복제 정책**:
- `000`: 복제 없음 (개발 환경)
- `001`: 같은 랙에 1개 복제
- `010`: 다른 랙에 1개 복제
- `100`: 다른 데이터센터에 1개 복제

### Volume 설정

**주요 옵션**:

```bash
weed volume \
  -mserver=master:9333 \        # Master 서버 주소
  -port=8080 \                  # HTTP 포트
  -dir=/data/volume1 \          # 볼륨 데이터 디렉토리
  -max=100 \                    # 최대 볼륨 개수
  -dataCenter=dc1 \             # 데이터센터 이름
  -rack=rack1 \                 # 랙 이름
  -ip=volume \                  # 공개 IP/호스트명
  -compactionMBps=50 \          # Compaction 속도 제한 (MB/s)
  -index=leveldb                # 인덱스 타입 (leveldb=메모리 절약)
```

### Filer 설정 (필수)

**주요 옵션**:

```bash
weed filer \
  -master=master:9333 \         # Master 서버 주소
  -port=8888 \                  # HTTP 포트
  -ip=filer \                   # 공개 IP/호스트명
  -s3 \                         # S3 API 활성화 (필수)
  -s3.port=8333 \               # S3 API 포트 (필수)
  -collection=default \         # 기본 컬렉션
  -dataCenter=dc1 \             # 데이터센터
  -defaultReplication=000       # 복제 정책
```

**SADO 프로젝트 필수 플래그**:
- `-s3`: S3 API 활성화 (OHIF Viewer, AI 서비스 연동)
- `-s3.port=8333`: S3 API 포트 지정

**filer.toml** (메타데이터 저장소 설정):

```toml
[leveldb2]
enabled = true
dir = "/data/filerdb"

# 또는 MySQL 사용
# [mysql2]
# enabled = true
# hostname = "localhost"
# port = 3306
# username = "root"
# password = "password"
# database = "seaweedfs_filer"
```

## 트러블슈팅

### 문제 1: 컨테이너가 시작되지 않음

**증상**:
```bash
docker-compose ps
# seaweedfs-master   Exit 1
```

**해결**:
```bash
# 로그 확인
docker-compose logs seaweedfs-master

# 볼륨 권한 문제일 경우
docker-compose down -v
docker-compose up -d
```

### 문제 2: Master와 Volume 연결 안 됨

**증상**:
```bash
curl http://localhost:10402/status
# Connection refused
```

**해결**:
```bash
# Master가 먼저 시작되었는지 확인
curl http://localhost:10400/cluster/status

# Volume 로그 확인
docker-compose logs seaweedfs-volume

# healthcheck 추가
# docker-compose.yml의 seaweedfs-volume에:
depends_on:
  seaweedfs-master:
    condition: service_healthy
```

### 문제 3: 포트 충돌

**증상**:
```
Error starting userland proxy: listen tcp4 0.0.0.0:10400: bind: address already in use
```

**해결**:
```bash
# 포트 사용 확인 (Windows)
netstat -ano | findstr :10400

# 프로세스 종료 또는 다른 포트 사용
```

### 문제 4: Volume 디스크 공간 부족

**증상**:
```json
{
  "error": "no free volumes"
}
```

**해결**:
```bash
# Volume 늘리기
docker-compose stop seaweedfs-volume
# docker-compose.yml에서 -max=100 → -max=200
docker-compose up -d seaweedfs-volume

# 또는 새 Volume 추가 (Master에 요청)
curl "http://localhost:10400/vol/grow?count=10"
```

### 문제 5: 메모리 부족

**증상**:
```
OOM killed
```

**해결**:
```yaml
# docker-compose.yml에 메모리 제한 추가
services:
  seaweedfs-volume:
    # ...
    deploy:
      resources:
        limits:
          memory: 2G
        reservations:
          memory: 1G
```
