# 06. 복제 및 고가용성

> **학습 목표**: SeaweedFS의 복제 전략과 고가용성 구성을 이해합니다.

---

## 복제 정책 (Replication Strategy)

### 3자리 복제 코드

SeaweedFS는 **3자리 숫자**로 복제 정책을 표현합니다:

```
복제 코드 형식: XYZ
  │││
  ││└─ Volume Server 복제 개수
  │└── Rack 복제 개수
  └─── DataCenter 복제 개수
```

**총 복제본 개수** = 1 + X + Y + Z

### 주요 복제 코드

| 코드 | 의미 | 총 복제본 | 사용 시나리오 |
|-----|------|----------|-------------|
| **000** | 복제 없음 | 1 | 개발 환경, 임시 데이터 |
| **001** | 같은 랙에 1개 | 2 | 단일 서버 장애 대비 |
| **010** | 다른 랙에 1개 | 2 | 랙 장애 대비 |
| **100** | 다른 DC에 1개 | 2 | 데이터센터 장애 대비 |
| **200** | 다른 DC에 2개 | 3 | 멀티 DC HA |
| **110** | 다른 랙 1개 + 다른 DC 1개 | 3 | 하이브리드 HA |

### 설정 방법

**Master 시작 시 기본값 설정**:
```bash
weed master -defaultReplication=001
```

**파일 업로드 시 개별 설정**:
```bash
curl "http://localhost:10400/dir/assign?replication=100"
```

## 일관성 모델

### Strong Consistency (강력한 일관성)

SeaweedFS는 **W = N, R = 1** 모델을 사용합니다:

- **W = N**: 모든 복제본에 쓰기 성공해야 완료
- **R = 1**: 1개 복제본만 읽으면 됨

**장점**:
- ✅ 항상 최신 데이터 읽기 보장
- ✅ 데이터 손실 위험 최소화

**단점**:
- ❌ 1개 서버라도 실패하면 쓰기 실패
- ❌ 쓰기 성능 저하 (모든 복제본 대기)

## Master 고가용성 (Raft)

### Raft 합의 알고리즘

Master는 **Raft 알고리즘**으로 HA를 구현합니다:

```
┌──────────┐
│ Master 1 │ ← Leader (Active)
├──────────┤
│ Master 2 │ ← Follower (Standby)
├──────────┤
│ Master 3 │ ← Follower (Standby)
└──────────┘
```

### Master 클러스터 구성

**3대 Master 구성**:

```yaml
# docker-compose.yml
services:
  master1:
    image: chrislusf/seaweedfs:latest
    command: 'master -ip=master1 -port=9333 -peers=master1:9333,master2:9333,master3:9333 -mdir=/data'
    ports:
      - "10400:9333"

  master2:
    image: chrislusf/seaweedfs:latest
    command: 'master -ip=master2 -port=9333 -peers=master1:9333,master2:9333,master3:9333 -mdir=/data'
    ports:
      - "10410:9333"

  master3:
    image: chrislusf/seaweedfs:latest
    command: 'master -ip=master3 -port=9333 -peers=master1:9333,master2:9333,master3:9333 -mdir=/data'
    ports:
      - "10420:9333"
```

### 리더 선출

- **초기 시작**: 3대 중 1대가 Leader로 선출
- **Leader 장애**: 5초 이내에 새 Leader 자동 선출
- **과반수 필요**: 최소 2대 살아있어야 클러스터 작동

## Volume Server 복제

### 데이터센터 및 랙 설정

```bash
# DataCenter=dc1, Rack=rack1
weed volume -mserver=master:9333 -dataCenter=dc1 -rack=rack1 -port=8080 -dir=/data1

# DataCenter=dc1, Rack=rack2
weed volume -mserver=master:9333 -dataCenter=dc1 -rack=rack2 -port=8081 -dir=/data2

# DataCenter=dc2, Rack=rack1
weed volume -mserver=master:9333 -dataCenter=dc2 -rack=rack1 -port=8082 -dir=/data3
```

### 복제 배치 예시

**복제 코드: 001** (같은 랙 1개 복제)

```
dc1/rack1/server1: Volume 1 (원본)
dc1/rack1/server2: Volume 1 (복제본)
```

**복제 코드: 010** (다른 랙 1개 복제)

```
dc1/rack1/server1: Volume 1 (원본)
dc1/rack2/server3: Volume 1 (복제본)
```

**복제 코드: 100** (다른 DC 1개 복제)

```
dc1/rack1/server1: Volume 1 (원본)
dc2/rack1/server4: Volume 1 (복제본)
```

## Erasure Coding (Warm Storage)

### 개념

Erasure Coding은 **스토리지 비용 절감**을 위한 기술입니다:

- **HOT 데이터**: 복제 사용 (빠른 접근)
- **WARM 데이터**: Erasure Coding 사용 (저렴한 저장)

### Erasure Coding 10.4

**10.4 Erasure Coding**:
- 10개 데이터 조각 + 4개 패리티 조각
- 총 14개 조각 중 10개만 있으면 복구 가능
- 스토리지 오버헤드: 140% (vs 복제 200%)

### 설정

```bash
weed master -volumeSizeLimitMB=30000 -defaultReplication=001

# Volume을 Erasure Coding으로 변환
curl "http://localhost:9333/vol/vacuum?garbageThreshold=0.3&collection=photos"
```

## Filer 고가용성

### Filer 클러스터

Filer는 **Stateless**이므로 수평 확장 가능:

```yaml
services:
  filer1:
    image: chrislusf/seaweedfs:latest
    command: 'filer -master=master1:9333,master2:9333,master3:9333 -ip=filer1'
    ports:
      - "10403:8888"

  filer2:
    image: chrislusf/seaweedfs:latest
    command: 'filer -master=master1:9333,master2:9333,master3:9333 -ip=filer2'
    ports:
      - "10413:8888"
```

### 메타데이터 저장소 HA

**MySQL 복제**:
```toml
[mysql2]
enabled = true
hostname = "mysql-master"
port = 3306
username = "root"
password = "password"
database = "seaweedfs_filer"
```

## SADO 프로젝트 설정

### 개발 환경 (복제 없음)

```yaml
services:
  seaweedfs-master:
    command: 'master -ip=seaweedfs-master -port=9333 -defaultReplication=000'

  seaweedfs-volume:
    command: 'volume -mserver=seaweedfs-master:9333 -port=8080'
```

### 프로덕션 환경 (001 복제)

```yaml
services:
  seaweedfs-master:
    command: 'master -ip=seaweedfs-master -port=9333 -defaultReplication=001'

  seaweedfs-volume1:
    command: 'volume -mserver=seaweedfs-master:9333 -port=8080 -dataCenter=dc1 -rack=rack1'

  seaweedfs-volume2:
    command: 'volume -mserver=seaweedfs-master:9333 -port=8081 -dataCenter=dc1 -rack=rack1'
```
