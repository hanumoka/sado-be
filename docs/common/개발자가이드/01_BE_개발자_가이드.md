## 4. 아키텍처 개요

### 4.1 시스템 아키텍처

```
┌─────────────┐     ┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│   sado_fe   │────▶│ Nginx Cache │────▶│  sado-minipacs   │────▶│   MySQL     │
│  (React)    │     │  (10202)    │     │  (Spring Boot)   │     │  (10100)    │
│  (10300)    │     └─────────────┘     │    (10201)       │     └─────────────┘
└─────────────┘           │             └────────┬─────────┘
                          │                      │
                    ┌─────┴─────┐                ▼
                    │  7일 캐시  │       ┌─────────────────┐
                    │ (frames,  │       │   SeaweedFS     │
                    │  rendered,│       │   S3 API        │
                    │  thumbnail)       │   (10405)       │
                    └───────────┘       └─────────────────┘
```

### 4.2 캐시 계층

```
Browser Cache (max-age=3600)
    ↓
Nginx Cache (7d TTL) - frames, rendered, thumbnail
    ↓
Caffeine L1 Cache (1h TTL) - Study/Series/Instance UID 조회
    ↓
MySQL + SeaweedFS
```

### 4.3 데이터 흐름

```
[DICOM 업로드 흐름]
1. Client → POST /dicomweb/studies (MultipartFile)
2. DicomWebController → DicomUploadService.upload()
3. DicomParseService → DCM4CHE로 DICOM 태그 파싱
4. Identity Resolution → Patient/Study/Series 매칭/생성
5. SeaweedFS → S3 API로 파일 저장
6. MySQL → 메타데이터 저장
7. PreRenderingService → 썸네일/프레임 생성 (동기)
8. Response → DICOM JSON (저장된 UID 목록)

[DICOM 조회 흐름]
1. Client → GET /dicomweb/studies/{uid}/series/{uid}/instances/{uid}/rendered
2. Nginx Cache 확인 (HIT 시 즉시 반환)
3. Caffeine Cache 확인 (Instance UID → ID 매핑)
4. MySQL → Instance 메타데이터 조회
5. SeaweedFS → 사전 렌더링된 파일 반환
6. Nginx Cache 저장 (7일)
7. Response → image/jpeg 또는 image/png
```

```sql
-- patients 테이블
CREATE TABLE patients (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    dicom_patient_id LONGTEXT,              -- DICOM (0010,0020)
    issuer_of_patient_id LONGTEXT,          -- 환자 ID 발급기관
    dicom_patient_name LONGTEXT,
    normalized_name VARCHAR(255),           -- 검색 최적화
    dicom_patient_birth_date VARCHAR(32),
    birth_date DATE,                        -- 검색 최적화
    dicom_patient_sex VARCHAR(16),
    content_hash VARCHAR(64) NOT NULL,      -- 중복 방지
    created_at DATETIME(6) DEFAULT CURRENT_TIMESTAMP(6),
    updated_at DATETIME(6) DEFAULT CURRENT_TIMESTAMP(6) ON UPDATE CURRENT_TIMESTAMP(6),

    UNIQUE KEY uk_patient_hash (tenant_id, content_hash),
    INDEX idx_tenant_name (tenant_id, normalized_name),
    INDEX idx_tenant_birth (tenant_id, birth_date)
);

-- instances 테이블 (핵심)
CREATE TABLE instances (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    study_id BIGINT NOT NULL,
    series_id BIGINT NOT NULL,
    sop_instance_uid LONGTEXT NOT NULL,
    sop_class_uid LONGTEXT,

    -- 이미지 정보
    rows INT,
    columns INT,
    photometric_interpretation VARCHAR(32),

    -- Cine 정보 (초음파)
    number_of_frames INT DEFAULT 1,
    frame_time FLOAT,
    cine_rate FLOAT,
    heart_rate FLOAT,

    -- 저장 정보
    storage_path VARCHAR(512) NOT NULL,
    file_size BIGINT,

    -- 사전 렌더링 상태
    transcoding_status VARCHAR(32) DEFAULT 'PENDING',
    thumbnail_path VARCHAR(512),
    frames_path VARCHAR(512),

    -- Tiering
    storage_tier VARCHAR(16) DEFAULT 'HOT',
    last_accessed_at DATETIME(6),
    access_count INT DEFAULT 0,

    -- JSON 확장 필드
    ultrasound_regions JSON,
    extended_metadata JSON,

    content_hash VARCHAR(64) NOT NULL,
    created_at DATETIME(6) DEFAULT CURRENT_TIMESTAMP(6),

    UNIQUE KEY uk_instance_hash (tenant_id, content_hash),
    INDEX idx_tenant_series (tenant_id, series_id),
    INDEX idx_tiering (tenant_id, storage_tier, last_accessed_at)
```

## 8. DICOM 처리 파이프라인

### 8.1 업로드 파이프라인

```java
@Service
@RequiredArgsConstructor
public class DicomUploadService {

    @Transactional
    public UploadResult upload(MultipartFile file, String tenantId) {
        // 1. DICOM 파싱
        DicomData dicomData = dicomParseService.parse(file.getInputStream());

        // 2. 검증
        ValidationResult validation = validationService.validate(dicomData);
        if (!validation.isValid()) {
            throw new InvalidDicomException(validation.getErrors());
        }

        // 3. Identity Resolution (Patient/Study/Series 매칭)
        Patient patient = identityService.resolvePatient(tenantId, dicomData);
        Study study = identityService.resolveStudy(tenantId, patient, dicomData);
        Series series = identityService.resolveSeries(tenantId, study, dicomData);

        // 4. 중복 체크
        String contentHash = HashUtil.sha256(file.getBytes());
        if (instanceRepository.existsByTenantIdAndContentHash(tenantId, contentHash)) {
            throw new DuplicateInstanceException(dicomData.getSopInstanceUid());
        }

        // 5. SeaweedFS 저장
        String storagePath = storageService.store(file, tenantId, dicomData);

        // 6. Instance 생성
        Instance instance = Instance.builder()
            .tenantId(tenantId)
            .series(series)
            .study(study)
            .sopInstanceUid(dicomData.getSopInstanceUid())
            .storagePath(storagePath)
            .fileSize(file.getSize())
            .contentHash(contentHash)
            .build();

        instance = instanceRepository.save(instance);

        // 7. 사전 렌더링 (동기)
        preRenderingService.render(instance);

        return new UploadResult(instance);
    }
}
```

```java
public class EchoValidator implements DicomValidator {
    @Override
    public ValidationResult validate(DicomData data) {
        if (!"US".equals(data.getModality())) {
            return ValidationResult.skip();
        }

        List<String> warnings = new ArrayList<>();

        // Cine 정보 검증
        if (data.getNumberOfFrames() > 1) {
            if (data.getFrameTime() <= 0 && data.getCineRate() <= 0) {

// Level 3: Identity 검증
public class IdentityValidator implements DicomValidator {
    @Override
    public ValidationResult validate(DicomData data) {
        TrustLevel trustLevel = TrustLevel.UNVERIFIED;

        if (hasValidIssuer(data) && canMatchEmr(data)) {
            trustLevel = TrustLevel.VERIFIED;
        } else if (isAnonymized(data)) {
            trustLevel = TrustLevel.EDUCATIONAL;
        } else if (passedBasicValidation(data)) {
            trustLevel = TrustLevel.RESEARCH;
        }

        return new ValidationResult(true, trustLevel);
    }
```

### 8.3 사전 렌더링 서비스

```java
@Service
public class PreRenderingService {

    public void render(Instance instance) {
        try {
            DicomData dicomData = loadDicomData(instance);

            // 1. 썸네일 생성 (128x128)
            BufferedImage thumbnail = renderFrame(dicomData, 0, 128);
            String thumbnailPath = storageService.storeThumbnail(instance, thumbnail);

            // 2. Cine 프레임 생성 (멀티 프레임인 경우)
            if (dicomData.getNumberOfFrames() > 1) {
                // 256px, 128px 두 가지 해상도
                List<String> framePaths = new ArrayList<>();

                for (int i = 0; i < dicomData.getNumberOfFrames(); i++) {
                    BufferedImage frame256 = renderFrame(dicomData, i, 256);
                    BufferedImage frame128 = renderFrame(dicomData, i, 128);

                    framePaths.add(storageService.storeFrame(instance, i, frame256, 256));
                    framePaths.add(storageService.storeFrame(instance, i, frame128, 128));
                }
            }

            // 3. 상태 업데이트
            instance.setTranscodingStatus("COMPLETED");
            instance.setThumbnailPath(thumbnailPath);
            instanceRepository.save(instance);

        } catch (Exception e) {
            log.error("Pre-rendering failed for instance: {}", instance.getId(), e);
            instance.setTranscodingStatus("FAILED");
            instanceRepository.save(instance);
        }
    }

    private BufferedImage renderFrame(DicomData data, int frameIndex, int size) {
        // DCM4CHE + OpenCV로 렌더링
        BufferedImage original = dicomImageReader.read(data, frameIndex);
        return ImageUtil.resize(original, size, size);
    }
}
```

### 9.2 Storage Service

```java
@Service
@RequiredArgsConstructor
public class SeaweedFsStorageService {

    private final S3Client s3Client;

    @Value("${seaweedfs.s3.bucket}")
    private String bucket;

    public String store(MultipartFile file, String tenantId, DicomData data) {
        String key = buildStoragePath(tenantId, data);

        PutObjectRequest request = PutObjectRequest.builder()
            .bucket(bucket)
            .key(key)
            .contentType("application/dicom")
            .build();

        s3Client.putObject(request, RequestBody.fromBytes(file.getBytes()));

        return key;
    }

    public byte[] retrieve(String storagePath) {
        GetObjectRequest request = GetObjectRequest.builder()
            .bucket(bucket)
            .key(storagePath)
            .build();

        return s3Client.getObjectAsBytes(request).asByteArray();
    }

    public void delete(String storagePath) {
        DeleteObjectRequest request = DeleteObjectRequest.builder()
            .bucket(bucket)
            .key(storagePath)
            .build();

        s3Client.deleteObject(request);
    }

    private String buildStoragePath(String tenantId, DicomData data) {
        // tenants/{tenantId}/studies/{studyUID}/series/{seriesUID}/instances/{sopUID}.dcm
        return String.format("tenants/%s/studies/%s/series/%s/instances/%s.dcm",
            tenantId,
            data.getStudyInstanceUid(),
            data.getSeriesInstanceUid(),
            data.getSopInstanceUid()
        );
    }
}
```

### 15.1 성능 최적화

```java
// 1. Virtual Thread 활용 (Java 21)
@Async
@Bean
public Executor asyncExecutor() {
    return Executors.newVirtualThreadPerTaskExecutor();
}

// 2. 비동기 사전 렌더링
@Async
public CompletableFuture<Void> renderAsync(Instance instance) {
    preRenderingService.render(instance);
    return CompletableFuture.completedFuture(null);
}

// 3. 병렬 프레임 처리
List<CompletableFuture<String>> futures = IntStream.range(0, frameCount)
    .mapToObj(i -> CompletableFuture.supplyAsync(() ->
        renderFrame(instance, i), executor))
    .toList();

CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
```

```java
@Entity
public class AnalysisResult {
    @Id @GeneratedValue
    private Long id;

    @ManyToOne
    private Study study;

    private String analysisType;  // EF, SEGMENTATION
    private String status;        // PENDING, COMPLETED, FAILED

    @Column(columnDefinition = "JSON")
    private String resultJson;    // AI 결과 JSON

    private LocalDateTime analyzedAt;
}

// Webhook 알림
@Service
public class WebhookService {
    public void notifyAnalysisComplete(Study study, AnalysisResult result) {
        WebhookPayload payload = WebhookPayload.builder()
            .event("analysis.completed")
            .studyUid(study.getStudyInstanceUid())
            .result(result.getResultJson())
            .build();

        webhookClient.send(payload);
    }
}
```
